# S10 串口配置与连接排查

## 常用连接参数

串口两端必须使用相同 baudrate、bytesize、parity、stopbits（常写作 8N1）。项目默认值位于 `project.serial`；GUI 可临时覆盖。端口名由操作系统枚举，例如 Windows `COM5`，Linux `/dev/ttyUSB0`，macOS `/dev/tty.usbserial-*`。

USB-UART 转换器通常需要安装对应驱动。S10 只列出操作系统可见端口，不安装驱动、不自动探测波特率。

## 错误提示建议

| 现象 | 建议提示 |
|---|---|
| 端口没有出现在列表 | 检查 USB 线、设备供电、驱动和设备管理器；点击刷新 |
| access denied / permission denied | 端口可能被其他串口工具占用；关闭占用程序后重试 |
| 参数无效 | 按设备固件或板卡文档核对波特率、数据位、校验和停止位 |
| 采集期间设备断开 | 已尽量保存断开前收到的数据；重新连接设备后启动新会话 |
| 输出写入失败 | 检查目标磁盘空间和目录权限；当前会话会标记为错误 |

这些是排查建议，不是根因判定。界面应保留底层异常文本供用户定位，不自动切换端口/波特率或重连。
