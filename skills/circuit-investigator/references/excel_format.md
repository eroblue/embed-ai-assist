# 硬件事实报告 Excel 格式规范（circuit_facts.xlsx）

> 格式蓝本：`assets/circuit_facts_example.xlsx`（源自《GD32F205VET_pin_config.xlsx》）。

## Sheet 1：`<MCU型号> 引脚配置`

列结构（6 列，前 5 列与蓝本一致，追加状态列）：

| 列 | 内容 | 示例 |
|----|------|------|
| A 引脚号 | 主控物理引脚号 | `34` |
| B 引脚名 | 芯片引脚名 | `PA0-WKUP` |
| C 网络 | 网络名（NC 显示 `-`） | `UART2_TX` |
| D 作用 | 推断的中文角色 | `串口2发送` |
| E 外设/模式 | 外设与配置模式 | `USART2_TX` |
| F 状态 | ok 留空 / 待确认 / 冲突 / NC | `待确认` |

- 表头：蓝底（`4472C4`）白字加粗，冻结首行
- 数据行按「外设/模式」类别整行着色（与蓝本图例一致，见下表）
- 未推断出的引脚（外设列为 `-`）不着色

## 类别 → 填充色（与蓝本一致）

| 颜色 | 色值 | 类别 | 典型外设/模式值 |
|------|------|------|----------------|
| 浅蓝 | `D9E1F2` | 电源/地/参考 | `电源` |
| 黄色 | `FFF2CC` | 复位/晶振/BOOT/调试 | `LXTAL`、`HXTAL`、`SWD`、`复位`、`BOOT` |
| 绿色 | `E2EFDA` | 数字输入（按键/旋钮/开关） | `GPIO 输入上拉` |
| 橙色 | `FCE4D6` | 模拟输入 ADC | `ADC012_IN8` |
| 浅蓝 | `DDEBF7` | GPIO 输出控制 / UART 串口 | `GPIO 输出`、`USART1_TX` |
| 紫色 | `E4DFEC` | SPI / I2C | `SPI2_MOSI`、`I2C1_SCL` |
| 粉红 | `F2DCDB` | 定时器 PWM | `TIMER PWM` |
| 灰色 | `EDEDED` | FSMC / EXMC 并口 | `EXMC_D4` |
| 无填充 | — | 未连接（NC） | `-` |

## Sheet 2：`图例`

1. 「颜色分组」：色块 + 类别说明（同上表，与蓝本结构一致）
2. 「状态说明」：
   - `待确认`（橙字）：网络名无明确语义，无法推断功能角色，建议人工/AI 补充
   - `冲突`（红字加粗）：存在复用冲突或电源缺失等 error 级问题，必须修复
   - `NC`（灰字）：网表中无连接的引脚
