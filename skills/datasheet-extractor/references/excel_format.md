# Excel 输出格式规范（datasheet-extractor）

两类 Excel 产物均输出到 `outputs/chip_info/`。

## pin_table.xlsx — 引脚定义表

**单工作表平铺**（单芯片引脚量级 20-216 行，平铺便于通读与筛选）。

- 工作表名：`引脚定义`
- 第 1 行：标题（合并单元格，如 `LQFP144 引脚定义（共 144 脚）`）
- 第 2 行：表头（深蓝底白字加粗）
- 第 3 行起：每个引脚一行

| 列 | 内容 | 示例 |
|----|------|------|
| 引脚号 | 封装管脚位号 | 1 |
| 引脚名 | 引脚名 | PE2 |
| 类型 | IO / 电源 / 输入 / 输出 / 启动 / 复位 | IO |
| 复用功能（默认） | AFIO remap 前的复用，` / ` 分隔 | TRACECK / FSMC_A23 |
| 复用功能（重映射） | AFIO remap 后的复用 | TIM2_CH1 / TIM2_ETR |
| 电气特性 | IO 电平（FT=5V 容忍） | FT |

**行颜色**：电源引脚=蓝底（D9E1F2）、含复用功能引脚=黄底（FFF2CC）、普通 IO=白底。

## register_map.xlsx — 寄存器映射表

**每个外设一个工作表**（寄存器总量可达上千条，按外设分组查阅；
工作表名截断至 31 字符）。

- 工作表名：外设名（如 `GPIOA`、`RCC`）
- 第 1 行：表头（深蓝底白字加粗）

| 列 | 内容 | 示例 |
|----|------|------|
| 外设 | 所属外设 | GPIOA |
| 寄存器名 | 寄存器名 | CRL |
| 地址 | 绝对地址 | 0x40010800 |
| 偏移 | 相对外设基地址 | 0x00 |
| 位域 | `位段名[bits]` 以 `; ` 连接 | MODE0[1:0]; CNF0[3:2] |
| 读写权限 | r/w/rw 等 | rw |
| 复位值 | 复位值 | 0x44444444 |
| 功能说明 | 功能描述 | 端口配置低寄存器 |

**无参考手册时**该文件不生成（registers 数据为空）。
