# S11 日志输入格式

## S10 `capture.log`

- UTF-8 JSON Lines，读取 `header`、`rx` 和 `decode_tail` 记录。
- 串口读取块可能切开一行；S11 按接收顺序拼接 `rx.text`，再按换行建立逻辑行和 evidence ID。
- 索引记录逻辑行对应的 `capture.log` 行号及可用的 `ts_host`。`ts_host` 是主机接收时间，不是设备生成时间。
- 有 `session.json` 时读取会话起止、停止原因、串口配置、接收统计和固件哈希等上下文。只使用实际存在的字段。
- 保留源文件不变。需要查看原始字节时由用户明确提供 `capture.bin` 和编码；S11 不猜解码方式。

## 普通文本

- 默认 UTF-8；确知其他编码时使用 `--encoding` 指定。
- 按物理行分配 evidence ID，保留原始行号和日志内容。替代字符或读取错误写入解析警告。
- 多个来源各自保留来源 ID 和行序。没有可靠的共同时间信息时，不跨文件推断事件先后。
